## Compute and GPU Role Separation

Refined the rack design around two different responsibilities: general infrastructure under Proxmox and a GPU-oriented system for AI compute. The distinction mattered because model inference, experimentation, and possible Vast.ai workloads could consume resources in ways that should not destabilize databases, networking, or other persistent services.

The existing NAS remained useful as a backup and shared-storage anchor while the rack environment developed. The software direction included Ubuntu Server guests, Docker/Kubernetes workloads, Redis, databases, and local AI services, but the physical workload boundaries were kept explicit.

## Decision

GPU capacity would not be treated as generic spare compute. Local inference and externally scheduled GPU work needed predictable ownership and isolation, even if both ultimately shared the same physical server.

This became the basis for the later Supermicro/P100 role: Proxmox could still provide virtualization and infrastructure integration, while the GPU host remained recognizably an AI compute node rather than becoming an undifferentiated application server.
