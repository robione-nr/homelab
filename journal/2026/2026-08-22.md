## VPS–Homelab File Synchronization

Designed the website synchronization path around Unison over SSH, controlled from the homelab utility LXC. Homelab project content lived on CephFS under `/cluster-data/www`, while VPS project trees remained deployable working copies under `/var/www`.

The goal was bidirectional synchronization without treating every file as portable. Repository metadata could remain available, while host-specific configuration such as `etc` and transient/editor artifacts could be excluded from propagation.

## Why Unison

The requirement was not simply deployment from one authoritative source. Development and operational changes could occur on either side, so the synchronization layer needed to reconcile two working trees rather than behave like a one-way copy job.

## Result

A practical project synchronization model emerged: CephFS provided shared authoritative homelab storage, SSH provided the transport boundary, and Unison handled change reconciliation. Later work focused on making the continuous/watch behavior reliable enough to trust operationally.
