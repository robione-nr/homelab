## Agent Workflow and Memory Model

With VPS↔homelab MySQL, email, and website synchronization functioning, attention shifted from connectivity to how agents should actually use the available information.

Defined a dynamic Kanban workflow for liaison, writer, editor, researcher, and research-director roles. Tasks could be inserted, blocked, delegated, or reordered instead of forcing every request through a fixed pipeline.

The knowledge architecture separated retrieval from durable memory. Source material would feed RAG; durable facts, preferences, and decisions could enter Supermemory; fresh Hermes sessions would remain comparatively clean rather than accumulating all historical context directly in prompts.

## Result

The system gained a clearer information lifecycle: source → retrieval/candidate knowledge → curated durable state → task-specific agent context. This reduced the temptation to solve every memory problem by adding more prompt text and provided the conceptual basis for the later Librarian role.
