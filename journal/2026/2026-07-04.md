## Shared Administrative Scripts

Extended CephFS beyond application/storage use by establishing it as a shared location for administrative tooling. The goal was to make the same infrastructure scripts available from multiple physical hosts and VMs instead of maintaining independent copies that could drift.

This was especially useful as the number of Proxmox nodes, Kubernetes guests, and service systems increased. Operational tooling could be versioned and updated once while remaining reachable from the systems that needed it.

## Result

CephFS became part of the management plane as well as the data plane. The approach reduced duplicate scripts and helped establish the later pattern of keeping authoritative shared content on CephFS while exposing it to controlled execution environments.

Permissions and execution context still mattered: shared availability did not imply every service or agent should have unrestricted write access.
