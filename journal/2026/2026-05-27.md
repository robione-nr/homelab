## Rack Server Architecture

Formalized the Dell PowerEdge R630 as the core virtualization platform. Proxmox would run on bare metal, with VMs and LXCs providing isolation for infrastructure services and Kubernetes rather than installing the application stack directly on the host.

Storage planning deliberately avoided hiding all disks behind a large hardware RAID. Mirrored boot SSDs were favored for the host, while data devices would remain individually manageable so they could later participate in ZFS, striped mirrors, or Ceph without first undoing an opaque controller layout.

GPU workloads were considered separately from general infrastructure. The emerging architecture anticipated local inference, model serving, and eventual Kubernetes integration without forcing every GPU workload into the same scheduling model.

## Result

This established the layered architecture used afterward: physical servers → Proxmox → VMs/LXCs → Kubernetes/containers and services. It also preserved flexibility for the later Ceph deployment by making storage visibility and failure domains part of the design from the beginning.
