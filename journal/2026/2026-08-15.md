## VPS-to-Homelab Database Replication

Established working asynchronous replication from VPS MySQL 8.0.46 to MySQL 8.0.46 running in Kubernetes on Ceph RBD. Rather than exposing MySQL publicly, replication traffic crossed Tailscale through the `svc-utility` LXC and a socat relay.

Getting replication healthy also exposed infrastructure drift elsewhere. Cilium was repointed to the correct highly available Kubernetes API endpoint, and stale Ceph CSI monitor addresses were removed so storage components reflected the current Ceph topology.

## Verification

The replication channel completed with both MySQL replica threads healthy and zero reported lag during verification. The homelab database was therefore receiving current VPS state through a private transport while retaining Kubernetes/Ceph-backed persistence.

## Significance

This was more than a database feature. It demonstrated a reusable VPS↔homelab pattern: public services could remain on the VPS while selected state and compute capabilities were extended into the private cluster without opening internal databases directly to the Internet.
